# Contributing

This repository maintains Xianlin Lu’s bilingual design portfolio. Contributions should improve accessibility, performance, responsive behavior, or content accuracy.

Use Node.js 24, run `npm ci`, then `npm run dev`. Before submitting a change, run `npm run check`. Keep English and Chinese content aligned, preserve verified personal facts, and describe the change with its validation results.

Edit `AGENTS.md` for project guidance and run `bash scripts/sync-agent-rules.sh` to update the corresponding editor instructions.
